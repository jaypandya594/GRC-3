# iSecurify GRC Pricing Calculator — Chat Z AI Master Prompt (v2)

## Stack: React + Python (FastAPI) + MySQL + Nginx / Apache2 on Ubuntu
Server

---

## 1. WHAT YOU ARE BUILDING

**iSecurify** is a private, internal GRC (Governance, Risk & Compliance)
pricing calculator and quote management platform. It is used **only** by
iSecurify's own team — Sales Executives, Sales Managers, and the
CTO/leadership. There is no public sign-up or client self-serve portal.

### Core features

- **Quote Builder** — 6-step wizard to build a priced compliance
proposal (framework → tier → auditor fees → add-ons → GRC tools /
DPO/vCISO → review & submit)

- **Quote Workflow** — state machine: DRAFT → PENDING_REVIEW →
PENDING_FINANCE → APPROVED → SENT

- **Clients CRM** — lightweight prospect/customer tracker

- **Admin Panel** — pricing configuration (frameworks, tiers, price
matrix, auditor fees, add-ons, GRC tools, DPO packages, FX rate)

- **PDF Export** — professionally branded A4 quote PDF (logo, line
items, totals, payment terms, approval trail)

- **Dashboard** — pipeline metrics, revenue chart by month, top
frameworks, recent quotes

- **User Management** — Super Admin and Admin can create users, reset
passwords, block/unblock, and delete users (with scope restrictions per
role)

- **Role-Based Access** — 3 roles: Super Admin, Admin (Sales Manager),
User (Sales Executive)

## 5. USER ROLES & PERMISSIONS

### 🔴 Super Admin

**Seed:** `admin@isecurify.in` / `Admin@iSecurify2025!`

Full access to everything:

- All Admin Panel sections (frameworks, tiers, prices, auditor fees,
add-ons, GRC tools, DPO/vCISO, FX rate)

- **Full User Management:** create any user with any role, reset any
password, block/unblock any user, permanently delete any user (hard
delete, with confirmation modal)

- Cannot delete their own account

- View, approve, reject, or override **any** quote at any stage

- Access Audit Log (every action across all users)

- Edit tenant branding (logo, colors)

- Export any data

### 🟡 Admin — Sales Manager

**Seed:** `sales.manager@isecurify.in` / `Sales@Manager2025!`

- Create and manage clients

- Create, edit, submit quotes for approval

- View **all** quotes (across all Sales Executives)

- **First-level approval** of Sales Executive quotes (PENDING_REVIEW →
PENDING_FINANCE or APPROVED)

- Download PDF for any quote they can view

- **Scoped User Management:**

- ✅ Create new users with roles `sales_executive`, `finance`, or
`viewer` only (cannot create another `sales_manager` or `super_admin`)

- ✅ Reset password for any `sales_executive`, `finance`, or `viewer`
user

- ✅ Block (deactivate) or unblock any `sales_executive`, `finance`, or
`viewer` user

- ✅ Delete any `sales_executive`, `finance`, or `viewer` user (hard
delete, with confirmation modal)

- ❌ Cannot create, edit, block, or delete `sales_manager` or
`super_admin` accounts

- ❌ Cannot change their own role

- ❌ Cannot access Admin Panel pricing config

### 🟢 User — Sales Executive

**Seed:** `sales.exec@isecurify.in` / `Sales@Exec2025!`

- Create and manage their **own** clients

- Create quotes, save as DRAFT

- Submit quotes for Sales Manager review

- View **only their own** quotes

- Download PDF for their own quotes

- ❌ Cannot approve any quote

- ❌ Cannot see other users' quotes

### 🔵 Finance

**Seed:** `finance@isecurify.in` / `Finance@iSecurify2025!`

- View all quotes (read-only)

- Download any PDF

- Approve the `PENDING_FINANCE` stage only

- ❌ Cannot create quotes, clients, or access Admin Panel

### Auth flow

**Login:** `POST /api/auth/login` — accepts `{email, password}`,
verifies bcrypt hash, returns `{access_token, token_type, user}`. Set as
HTTP-only cookie on the response.

**Middleware dependency (use on every protected route):**

```python

# services/auth_service.py

from fastapi import Depends, HTTPException, status

from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

from jose import JWTError, jwt

security = HTTPBearer()

def get_current_user(credentials: HTTPAuthorizationCredentials =
Depends(security), db: Session = Depends(get_db)):

token = credentials.credentials

try:

payload = jwt.decode(token, settings.SECRET_KEY,
algorithms=[settings.ALGORITHM])

user_id = payload.get("sub")

if not user_id:

raise HTTPException(status_code=401, detail="Invalid token")

except JWTError:

raise HTTPException(status_code=401, detail="Invalid token")

user = db.query(User).filter(User.id == user_id, User.is_active ==
True).first()

if not user:

raise HTTPException(status_code=401, detail="User not found")

return user

def require_roles(*roles):

def dependency(current_user = Depends(get_current_user)):

if current_user.role not in roles:

raise HTTPException(status_code=403, detail="Insufficient permissions")

return current_user

return dependency

```

## 8. PRICING ENGINE (Python)

Port the TypeScript `quoteCalculator.ts` logic exactly to Python in
`backend/services/quote_calculator.py`.

**Calculation order:**

1. Consulting fee = `framework_price.project_fee_inr` for selected
`(framework_id, tier_id)`

2. If `include_retainer=True`, add `framework_price.retainer_fee_inr`

3. Sum all selected `auditor_fee.fee_inr` values

4. Sum all selected `addon_service.fee_inr` values

5. Add `grc_tool.fee_inr_annual` if selected

6. Add `dpo_vciso_package.fee_inr_monthly` or `fee_inr_annual` as
selected

7. **Internal time** (`internal_hours × internal_hourly_rate`) is
tracked but **NEVER added to subtotal or billed total**

8. `subtotal = sum of steps 1–6`

9. `discount_inr = subtotal × (discount_pct / 100)` OR flat
`discount_inr`

10. `gst_amount = (subtotal - discount_inr) × (gst_rate / 100)`

11. `total_inr = subtotal - discount_inr + gst_amount`

12. `total_usd = total_inr / usd_inr_rate`

**Save to `quote_line_items`** one row per component using `line_type`
enum.

## 9. PDF GENERATION (Python — WeasyPrint)

Generate the PDF in `backend/services/pdf_service.py` using WeasyPrint
(HTML → PDF). This is cleaner than jsPDF and produces better print
fidelity.

### PDF layout requirements (professional A4)

**Header (purple bar, full width):**

- Teal accent stripe 3mm at very top

- Orange rule 0.8mm below teal stripe

- Purple background `#812671` for the rest of the header (44mm tall)

- Logo left-aligned at `(20mm, 10mm)`, height 22mm, baseline-aligned
with company name text

- "iSecurify" bold 20pt white, on same row as logo

- "GRC Compliance Proposal" 9pt light purple below company name

- Quote ID badge (white rounded pill) on same row, right of the subtitle

- Right side: Date, Valid Until, Version — 9pt white

- Status badge (coloured pill) bottom-right of header

**Body sections** — each section has:

- Section title: 12pt bold in brand colour, with full-width underline
rule

- 8mm gap above each section title

- 6mm gap between label/value rows within a section

**Required sections in order:**

### Authentication

Use Axios with a request interceptor that attaches the JWT from
localStorage:

```ts

// src/lib/api.ts

import axios from 'axios'

import { useAuthStore } from '@/store/authStore'

const api = axios.create({ baseURL: '/api' })

api.interceptors.request.use(config => {

const token = useAuthStore.getState().token

if (token) config.headers.Authorization = `Bearer ${token}`

return config

})

api.interceptors.response.use(

res => res,

err => {

if (err.response?.status === 401) {

useAuthStore.getState().logout()

window.location.href = '/login'

}

return Promise.reject(err)

}

)

export default api

```

## 12. WEB SERVER CONFIGURATION

### Option A — Nginx (RECOMMENDED)

Install: `sudo apt install nginx`

**`/etc/nginx/sites-available/isecurify`**

```nginx

server {

listen 80;

server_name YOUR_DOMAIN_OR_IP;

# Frontend — React build (served as static files)

root /var/www/isecurify/frontend/dist;

index index.html;

# All frontend routes → index.html (React Router SPA)

location / {

try_files $uri $uri/ /index.html;

}

# API → FastAPI (Uvicorn on port 8000)

location /api/ {

proxy_pass http://127.0.0.1:8000;

proxy_http_version 1.1;

proxy_set_header Host $host;

proxy_set_header X-Real-IP $remote_addr;

proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

proxy_set_header X-Forwarded-Proto $scheme;

proxy_read_timeout 120s;

proxy_connect_timeout 10s;

}

# Static uploads

location /uploads/ {

alias /var/www/isecurify/uploads/;

expires 7d;

add_header Cache-Control "public";

}

# Security headers

add_header X-Frame-Options "SAMEORIGIN";

add_header X-Content-Type-Options "nosniff";

add_header X-XSS-Protection "1; mode=block";

add_header Referrer-Policy "strict-origin-when-cross-origin";

# Gzip

gzip on;

gzip_types text/plain application/json application/javascript text/css;

client_max_body_size 20M;

}

```

nginx`

## 16. KNOWN ISSUES TO AVOID

1. **Do not mix Indian lakh format with Western comma format** — pick
lakh everywhere (₹10,00,000 not ₹1,000,000).

2. **Never add internal_time line items to the billed subtotal** — they
are tracked for internal cost reporting only.

3. **Tenant-specific framework prices override global prices** — always
try `tenant_id = TENANT_ID` first, fall back to `tenant_id IS NULL`.

4. **Quote state machine is one-directional** — `APPROVED` cannot go
back to `DRAFT`. The only exception is `recalled` action by the creator.

5. **PDF amounts must use Indian lakh format** — same as UI.

6. **Finance role can only approve at `PENDING_FINANCE` stage** — not at
`PENDING_REVIEW`.

7. **User deletion requires quote reassignment** — before hard-deleting
a user, reassign all their `quotes.created_by_id` to the deleting
admin's `id`. Never cascade-delete quotes when a user is removed. Show a
warning in the confirmation modal if the user has open quotes.

8. **Password minimum requirements** — at least 8 chars, one uppercase,
one digit. Enforce in both the Pydantic schema (backend) and with a
real-time strength indicator in the UI (frontend).

9. **Sales Manager cannot elevate privileges** — the `POST /api/users`
and `PATCH /api/users/{id}` endpoints must server-side validate that a
`sales_manager` caller cannot set `role` to `sales_manager` or
`super_admin`. Reject with `403` if attempted.
