     8→## 1. WHAT YOU ARE BUILDING
     9→
    10→**iSecurify** is a private, internal GRC (Governance, Risk & Compliance)
    11→pricing calculator and quote management platform. It is used **only** by
    12→iSecurify's own team — Sales Executives, Sales Managers, and the
    13→CTO/leadership. There is no public sign-up or client self-serve portal.
    14→
    15→### Core features
    16→
    17→- **Quote Builder** — 6-step wizard to build a priced compliance
    18→proposal (framework → tier → auditor fees → add-ons → GRC tools /
    19→DPO/vCISO → review & submit)
    20→
    21→- **Quote Workflow** — state machine: DRAFT → PENDING_REVIEW →
    22→PENDING_FINANCE → APPROVED → SENT
    23→
    24→- **Clients CRM** — lightweight prospect/customer tracker
    25→
    26→- **Admin Panel** — pricing configuration (frameworks, tiers, price
    27→matrix, auditor fees, add-ons, GRC tools, DPO packages, FX rate)
    28→
    29→- **PDF Export** — professionally branded A4 quote PDF (logo, line
    30→items, totals, payment terms, approval trail)
    31→
    32→- **Dashboard** — pipeline metrics, revenue chart by month, top
    33→frameworks, recent quotes
    34→
    35→- **User Management** — Super Admin and Admin can create users, reset
    36→passwords, block/unblock, and delete users (with scope restrictions per
    37→role)
    38→
    39→- **Role-Based Access** — 3 roles: Super Admin, Admin (Sales Manager),
    40→User (Sales Executive)

   562→## 5. USER ROLES & PERMISSIONS
   563→
   564→### 🔴 Super Admin
   565→
   566→**Seed:** `admin@isecurify.in` / `Admin@iSecurify2025!`
   567→
   568→Full access to everything:
   569→
   570→- All Admin Panel sections (frameworks, tiers, prices, auditor fees,
   571→add-ons, GRC tools, DPO/vCISO, FX rate)
   572→
   573→- **Full User Management:** create any user with any role, reset any
   574→password, block/unblock any user, permanently delete any user (hard
   575→delete, with confirmation modal)
   576→
   577→- Cannot delete their own account
   578→
   579→- View, approve, reject, or override **any** quote at any stage
   580→
   581→- Access Audit Log (every action across all users)
   582→
   583→- Edit tenant branding (logo, colors)
   584→
   585→- Export any data
   586→
   587→### 🟡 Admin — Sales Manager
   588→
   589→**Seed:** `sales.manager@isecurify.in` / `Sales@Manager2025!`
   590→
   591→- Create and manage clients
   592→
   593→- Create, edit, submit quotes for approval
   594→
   595→- View **all** quotes (across all Sales Executives)
   596→
   597→- **First-level approval** of Sales Executive quotes (PENDING_REVIEW →
   598→PENDING_FINANCE or APPROVED)
   599→
   600→- Download PDF for any quote they can view
   601→
   602→- **Scoped User Management:**
   603→
   604→- ✅ Create new users with roles `sales_executive`, `finance`, or
   605→`viewer` only (cannot create another `sales_manager` or `super_admin`)
   606→
   607→- ✅ Reset password for any `sales_executive`, `finance`, or `viewer`
   608→user
   609→
   610→- ✅ Block (deactivate) or unblock any `sales_executive`, `finance`, or
   611→`viewer` user
   612→
   613→- ✅ Delete any `sales_executive`, `finance`, or `viewer` user (hard
   614→delete, with confirmation modal)
   615→
   616→- ❌ Cannot create, edit, block, or delete `sales_manager` or
   617→`super_admin` accounts
   618→
   619→- ❌ Cannot change their own role
   620→
   621→- ❌ Cannot access Admin Panel pricing config
   622→
   623→### 🟢 User — Sales Executive
   624→
   625→**Seed:** `sales.exec@isecurify.in` / `Sales@Exec2025!`
   626→
   627→- Create and manage their **own** clients
   628→
   629→- Create quotes, save as DRAFT
   630→
   631→- Submit quotes for Sales Manager review
   632→
   633→- View **only their own** quotes
   634→
   635→- Download PDF for their own quotes
   636→
   637→- ❌ Cannot approve any quote
   638→
   639→- ❌ Cannot see other users' quotes
   640→
   641→### 🔵 Finance
   642→
   643→**Seed:** `finance@isecurify.in` / `Finance@iSecurify2025!`
   644→
   645→- View all quotes (read-only)
   646→
   647→- Download any PDF
   648→
   649→- Approve the `PENDING_FINANCE` stage only
   650→
   651→- ❌ Cannot create quotes, clients, or access Admin Panel

   860→### Auth flow
   861→
   862→**Login:** `POST /api/auth/login` — accepts `{email, password}`,
   863→verifies bcrypt hash, returns `{access_token, token_type, user}`. Set as
   864→HTTP-only cookie on the response.
   865→
   866→**Middleware dependency (use on every protected route):**
   867→
   868→```python
   869→
   870→# services/auth_service.py
   871→
   872→from fastapi import Depends, HTTPException, status
   873→
   874→from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
   875→
   876→from jose import JWTError, jwt
   877→
   878→security = HTTPBearer()
   879→
   880→def get_current_user(credentials: HTTPAuthorizationCredentials =
   881→Depends(security), db: Session = Depends(get_db)):
   882→
   883→token = credentials.credentials
   884→
   885→try:
   886→
   887→payload = jwt.decode(token, settings.SECRET_KEY,
   888→algorithms=[settings.ALGORITHM])
   889→
   890→user_id = payload.get("sub")
   891→
   892→if not user_id:
   893→
   894→raise HTTPException(status_code=401, detail="Invalid token")
   895→
   896→except JWTError:
   897→
   898→raise HTTPException(status_code=401, detail="Invalid token")
   899→
   900→user = db.query(User).filter(User.id == user_id, User.is_active ==
   901→True).first()
   902→
   903→if not user:
   904→
   905→raise HTTPException(status_code=401, detail="User not found")
   906→
   907→return user
   908→
   909→def require_roles(*roles):
   910→
   911→def dependency(current_user = Depends(get_current_user)):
   912→
   913→if current_user.role not in roles:
   914→
   915→raise HTTPException(status_code=403, detail="Insufficient permissions")
   916→
   917→return current_user
   918→
   919→return dependency
   920→
   921→```

   989→## 8. PRICING ENGINE (Python)
   990→
   991→Port the TypeScript `quoteCalculator.ts` logic exactly to Python in
   992→`backend/services/quote_calculator.py`.
   993→
   994→**Calculation order:**
   995→
   996→1. Consulting fee = `framework_price.project_fee_inr` for selected
   997→`(framework_id, tier_id)`
   998→
   999→2. If `include_retainer=True`, add `framework_price.retainer_fee_inr`
  1000→
  1001→3. Sum all selected `auditor_fee.fee_inr` values
  1002→
  1003→4. Sum all selected `addon_service.fee_inr` values
  1004→
  1005→5. Add `grc_tool.fee_inr_annual` if selected
  1006→
  1007→6. Add `dpo_vciso_package.fee_inr_monthly` or `fee_inr_annual` as
  1008→selected
  1009→
  1010→7. **Internal time** (`internal_hours × internal_hourly_rate`) is
  1011→tracked but **NEVER added to subtotal or billed total**
  1012→
  1013→8. `subtotal = sum of steps 1–6`
  1014→
  1015→9. `discount_inr = subtotal × (discount_pct / 100)` OR flat
  1016→`discount_inr`
  1017→
  1018→10. `gst_amount = (subtotal - discount_inr) × (gst_rate / 100)`
  1019→
  1020→11. `total_inr = subtotal - discount_inr + gst_amount`
  1021→
  1022→12. `total_usd = total_inr / usd_inr_rate`
  1023→
  1024→**Save to `quote_line_items`** one row per component using `line_type`
  1025→enum.

  1964→## 16. KNOWN ISSUES TO AVOID
  1965→
  1966→1. **Do not mix Indian lakh format with Western comma format** — pick
  1967→lakh everywhere (₹10,00,000 not ₹1,000,000).
  1968→
  1969→2. **Never add internal_time line items to the billed subtotal** — they
  1970→are tracked for internal cost reporting only.
  1971→
  1972→3. **Tenant-specific framework prices override global prices** — always
  1973→try `tenant_id = TENANT_ID` first, fall back to `tenant_id IS NULL`.
  1974→
  1975→4. **Quote state machine is one-directional** — `APPROVED` cannot go
  1976→back to `DRAFT`. The only exception is `recalled` action by the creator.
  1977→
  1978→5. **PDF amounts must use Indian lakh format** — same as UI.
  1979→
  1980→6. **Finance role can only approve at `PENDING_FINANCE` stage** — not at
  1981→`PENDING_REVIEW`.
  1982→
  1983→7. **User deletion requires quote reassignment** — before hard-deleting
  1984→a user, reassign all their `quotes.created_by_id` to the deleting
  1985→admin's `id`. Never cascade-delete quotes when a user is removed. Show a
  1986→warning in the confirmation modal if the user has open quotes.
  1987→
  1988→8. **Password minimum requirements** — at least 8 chars, one uppercase,
  1989→one digit. Enforce in both the Pydantic schema (backend) and with a
  1990→real-time strength indicator in the UI (frontend).
  1991→
  1992→9. **Sales Manager cannot elevate privileges** — the `POST /api/users`
  1993→and `PATCH /api/users/{id}` endpoints must server-side validate that a
  1994→`sales_manager` caller cannot set `role` to `sales_manager` or
  1995→`super_admin`. Reject with `403` if attempted.
